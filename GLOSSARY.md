# GNOME gestures

This project distinguishes vertical overview gestures from horizontal workspace gestures.

## Language

**Overview**:
GNOME's view of open windows and workspaces, with access to the application grid.

**Vertical three-finger swipe**:
A three-finger touchpad gesture moving primarily upward or downward.
_Avoid_: Overview gesture when describing the physical input

**Horizontal workspace swipe**:
A three-finger touchpad gesture moving primarily left or right to move between workspaces.
_Avoid_: Three-finger gesture without a direction
